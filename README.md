# MovieHub

A fast, mobile-first entertainment directory inspired by the information architecture of modern streaming directories.

## Included
- Responsive dark/glass UI
- Instant fuzzy-style local search
- Category filtering
- Local catalog in `data.js`
- No backend required
- GitHub Pages deployment via Actions
- Official/authorized entertainment destinations only

## GitHub Pages
Enable **Settings → Pages → GitHub Actions** if Pages is not already enabled. Every push to `main` deploys the site.

## Important
This project intentionally does not mirror or redistribute third-party copyrighted movies, streams, downloads, or a catalog of piracy links. It is a directory UI that can point to official/legal services.
